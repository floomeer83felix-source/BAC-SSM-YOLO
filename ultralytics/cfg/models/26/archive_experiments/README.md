# Archived YOLO26 Experiment YAMLs

This folder stores temporary or deprecated experiment YAML files moved out of the main `models/26` directory to reduce confusion.

Files here were not deleted. Move a YAML back to the parent directory if you need to reproduce an old experiment.

Kept in the parent directory:

- `yolo26.yaml`
- `yolo26s.yaml`
- official task variants such as `cls`, `seg`, `pose`, `obb`, `p2`, `p6`, and `yoloe`
- `yolo26-ss2d.yaml`
- `yolo26-ss2d-shufflefuse.yaml`
- `yolo26-cbr.yaml`
- `yolo26-ss2d-scdown-shufflefuse-cbr.yaml`
- `yolo26-rtdetrneck-cbr.yaml`
- `yolo26-ss2d-backboneonly.yaml`
- `yolo26-ss2d-neckonly.yaml`
